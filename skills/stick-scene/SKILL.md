# 火柴人讲解场景

每个场景用人物、实体道具和清晰动作解释一件事，通常为 5–8 秒。原生交付是零运行时依赖的 `<stick-scene>` Canvas 组件，可点击、悬停、进入视口或循环播放。完整讲解视频需要另行编排和导出。

## 项目边界

- 创作简报、场景标签、字幕和交付说明使用简体中文。上游代码、许可证及参考资料保留原文。
- 所有浏览器操作，包括预览、截图、取帧和测试，先读取 `~/.agents/skills/ego-browser/SKILL.md`，通过 ego-browser 执行。联网内容同时遵循 web-access 的访问边界。
- 上游 `scripts/frames.mjs`、`scripts/motion.mjs` 会启动 Playwright，在本项目中不能直接执行。可参考其采样和检测逻辑迁移至 ego-browser；不能完成时记录具体渲染待办，不能标记检查通过。
- 创作工程写入本项目当次 `history/YYYY-MM-DD/编号/` 目录，复制所需运行时和模板，不直接修改技能运行时或示例。保留 MIT 许可证。

## 创作流程

1. 明确讲解对象、观众需要理解的变化和来源事实。概括“输入 → 动作 → 可见结果”，区分事实与创作隐喻。
2. 提供 2–3 个实体隐喻供用户选择，例如传送带、杠杆、印章、便签板；用户已授权自行选择时，说明理由后继续。沿用已确认的内容形态和交付方式，只补充必要的时长、画幅与声音选择。
3. 编写前读取 [references/craft.md](references/craft.md)，按需要参考 [examples/diffity-review.js](examples/diffity-review.js)（评论、修复、审批的双人场景）或其他示例。上游完整流程见 [SKILL.upstream.md](SKILL.upstream.md)，其中浏览器命令必须按项目边界替换。
4. 从 [templates/scene.js](templates/scene.js) 起步，复制 [runtime/stick.js](runtime/stick.js) 到创作工程。运行时先于场景脚本加载，场景以 `STICK.SCENES` 注册，时间线按 `T = S.u * dur` 编排。先布局道具，再绘制人物与手持物。
5. 用 ego-browser 核验关键静帧，再检查完整动作。可参考 [templates/preview.html](templates/preview.html) 的 `frames=idle:0,s:1,s:2,u:1` 参数和 `STICK.at(element, {u:进度})` 定格接口。检查起止、接触、持物、转身与返回待机等节点；有 `S.n` 变体时覆盖各变体。
6. 检查裁切、中文排版、道具遮脸、手未碰到道具、关节跳变、穿脸、脚底滑动及首尾突跳。人物触及距离有限，先走近再伸手；姿态用插值衔接。静帧检查不能代替连续运动检查。

## 视觉与视频集成

- 保持墨黑 `#141414`、白纸、少量黄油色或强调色，以及充分留白。一个场景只表达一个核心变化，结尾给结果留出停顿。
- 人物头部与操作中的手必须可见；用杠杆、纸张、箱子等实体道具解释抽象流程。来源未证明的效果不能用字幕写成事实。
- 多场景讲解视频按分镜组合，每段承担一个论点，字幕和旁白在外层时间线安排。根据任务选择已安装的 HyperFrames 或其他项目动效方案，并继续遵守 ego-browser 约束。
- 不将上游小字号直接用于手机端长字幕；中文选择支持汉字的字体，按实际画幅核验可读性。离线预览可给组件添加 `no-font`，避免自动加载 Google Fonts。
- 网页交付使用 `<stick-scene scene="场景标识" play="view" label="中文说明">`；支持 `click`、`hover`、`loop`、`idle`，尺寸用 CSS 设置。视频采帧使用确定性的时间进度，不依赖实时悬停或滚动触发。
- 动画交付保留源码、封面、文案、来源记录、核验结果和 `manifest.json`，记录使用的技能、固定提交和工具。只有实际生成视频并核对尺寸、时长、帧率、字幕和音画同步后才能标记完成；否则设置 `videoStatus: "pending"` 并列明待办。

安装版本与验证范围见 [安装记录.md](安装记录.md)。
